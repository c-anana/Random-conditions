Every match is different. Each round, a random **condition** changes the rules: bombs that explode in strange ways, cursed players, radioactive zones, meteor storms, inverted controls and much more.

This project is still in testing and may contain bugs. If you find one, please open an issue on GitHub and describe what happened, which condition or command you used, and what you expected to see.

## What's inside

- **86 conditions**, from simple changes to chaotic ones.
- **4 bosses**: Stone Golem, Ice Mage, Bomber and a secret Bomb Boss.
- **Random events** during matches.
- **Sound and visual effects** for conditions and bosses.
- **5 languages**: English, Spanish, French, Portuguese and Russian.

## Install

1. Download `random_conditions.py`.
2. Copy it into your BombSquad mods folder.
3. Restart the game and start a match.

## Try it

Type these in the chat:

- `/con1` to `/con86`: start a specific condition
- `/boss 1`, `/boss 2`, `/boss 3`: start a boss
- `/eboss`: start the secret Bomb Boss
- `/evento`: start a random event

## Language

The mod follows your game language. You can also pick one in the mod settings. If your language isn't available, it uses English.

## Reporting bugs

Found something broken or strange? Open an issue on GitHub and include:

- What you were doing (condition, boss or command)
- What happened
- What you expected to happen
- Your BombSquad version, if you know it
